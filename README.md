# Monte Carlo Tree Search (MCTS)

A simple implementation of Monte Carlo Tree Search (MCTS) from scratch using Python and NumPy.

This project was created to practise my Python skills and develop my understanding of machine learning and search algorithms.

The implementation uses the UCT algorithm to balance exploration and exploitation and is demonstrated on Tic-Tac-Toe.

A Minimax player is also included to test the MCTS implementation against perfect play. With 1000 simulations per move, MCTS achieved 100 draws in 100 games against Minimax.
